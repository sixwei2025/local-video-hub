# 汇芯视频中心 · 设计规范

## 1. 电影幕布（必须保留）
- 位置：每个页面最顶部（工作台 index.html、客户展示 showcase.html），在顶栏之上。
- 构成：红色丝绒幕帘（波浪下摆）+ 金色流苏 + 两束缓慢摆动的追光 + 顶部红色舞台光晕。
- 实现：`static/cinema.css`（全部参数是 CSS 变量：`--curtain-h` 高度、`--curtain-scallop` 下摆宽、幕帘渐变色、流苏色与透明度、追光强度）。HTML 是一段固定结构：
  `<div class="curtain" aria-hidden="true"><div class="glow"></div><i class="beam l"></i><i class="beam r"></i><div class="valance"></div><div class="fringe"></div></div>`
- 规则：
  - **不得删除、不得替换成纯色条或细线**；改版、压缩顶栏、Codex 等外部建议都必须保留它。
  - 可以调高度（建议 28–42px），但顶栏仍要纤细、品牌名一行显示。
  - 不挡交互：`pointer-events:none`；尊重「减少动态效果」系统设置。
  - 新页面必须引入 `cinema.css` 并放上这段结构。

## 2. 品牌
- 主色 #C8102E，深色 #5C0614；顶栏最左是红底白字「汇」方块 + 「汇芯视频中心」（苹方 14px、字重 500、字距 .12em、不换行）+ 小号衬线 HUIXIN · VIDEO HUB。
- 红色只给：主按钮、选中态、徽标、焦点环、关键链接。

## 3. 色彩与字体
- 深色背景（--bg #0b0807），主文字奶白 #f6eddf，次要文字 --dim #b9ab98（保证对比度）。
- 宋体只用于大标题/展示页标题，其余苹方。
- 所有颜色写成 CSS 变量；状态色固定：制作中灰、失败暗红、待确认琥珀、待发布品牌红、已导出蓝、已发布绿。

## 4. 布局
- 只做桌面端；顶栏 56px，品牌区与导航 `flex:none; white-space:nowrap`，只有待办计数可收缩。
- 提示一律用 toast，确认用站内对话框；删除一律「移到废纸篓」，不可永久删除。

## 幕布英雄区（必须保留）
- 作品管理首页与 /showcase 必须保留完整幕布英雄区：红色丝绒幕布（扇形边+流苏）、深色舞台背景、「HUIXIN STUDIO · 本地运行」、大号衬线标题「汇芯视频中心」+短红线、副标题、实时数字行（作品/制作中/待确认/待发布/已发布/失败>0 才显示，可点击筛选）、数字下品牌红细条、行尾细竖线后接本周新增/今日发布（同款衬线、略小，无盒子）。英雄区只用奶油白、灰、品牌红，不放产线彩色堆叠条或图例（产线数字在左侧栏）。留白：数字行底部到导航栏顶约 72px（全页最大留白，hero 底 padding 64px + 渐隐，极淡分隔线居中；轻量版 28px），导航栏到内容区 36px，筛选栏到卡片 24px；英雄区内标题→红线 14px、副标题 14px、数字行 30px；用渐隐/极淡分隔线分隔。留白优先，1440 首屏露出半行卡片即可。
- 1440 宽时高度约 220–260px，首行卡片必须在首屏可见。
- 生成视频/发布页使用轻量版（幕布 + 小标题）。
- 英雄区下方保留细导航栏。不使用「汇」方形标志（任何页面都不要）；首页英雄区已有大标题，导航左侧不放品牌，标签靠左；其他页只用单行文字「汇芯视频中心」。
- 色值：品牌红 #C8102E，深红 #5C0614；页面不使用「汇」方形标志。禁止再简化为纯幕布条。

## 硬规则：每个作品只显示最新一版（2026-10-22）
- 同一选题 = 标题去掉版本号（v1/v2/第N版…）、空格、标点后相同，或视频 md5 相同；不分产线。
- 数据层最后关卡 `dedup_core.gate`：作品列表 API 和首页统计永远只返回同一选题最新一条（hub.py 提交的优先），其余就算在数据库里也不显示。
- 工程目录（`~/lab/*`、任何含 node_modules 的目录）不进网站；只放行已发布、风格样片、hub.py 提交的文件。
- 每次扫描后（含服务启动）自动去重：落选卡片记入 `data/hidden_cards.json` 并删记录；只有桌面产线文件夹里的旧成片移到废纸篓（已发布/精选/风格样片/1 小时内改过/读不出/中间件不动）。结果写 `data/删除记录.csv`。
- 自检：`.venv/bin/python data/dup_audit.py`，有重复退出码 1；`--fix` 自动清。
- 扫描白名单（2026-10-22 二次收紧）：只扫 config.json `output_dirs` 的桌面产线文件夹 + hub.py 登记的文件；~/hx-promo、~/GrokBridge、~/lab 等一律不扫。已发布、风格样片在白名单外按登记显示。
- 碎片：文件名/标题只剩一两个字母数字或 v/p2/film/raw/out/final 之类，一律不显示。
