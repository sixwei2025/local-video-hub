# 汇芯视频中心 优化总方案（六伟 2026-10-21）
核心路径：选效果 → 换成自己的内容 → 生成 → 确认成片 → 准备发布。
1 导航：主导航「生成视频 / 作品管理 / 发布」；任何页可达生成；顶部品牌区压缩。
2 生成：填内容、选样式（用真实视频效果展示）、开始；记住声音/画幅等上次选择，其他收进更多设置；案例卡加「照这个样式做一条」。
3 进度与结果同页：显示当前阶段；完成即预览+修改内容/重新生成/准备发布；失败说明卡点、可重试不重填。
4 Grokbot 自动成套交付：每次出片同时产出 视频+标题+简介+封面+话题，自动入库；开工即建作品记录（制作中）→ 核对一致与齐全 → 待确认。固定提交入口（API/CLI），不靠提示词。
5 作品与版本：按作品管理，视频/封面/字幕/初稿/修改版归一；默认显示已选定版本，历史可展开；改文案不重出视频；标「最新」「已选定」。
6 状态：制作中 / 待确认 / 待发布 / 已发布；精选为独立标记，废片为归档。首页显示待办计数可点击；口径统一。
7 卡片：标题、预览、状态、时长画幅，日期辅助；去重标签；统一精选；竖屏适配；筛选=搜索+状态+排序，其余更多筛选，条件chips+一键清除；理清产线/类型。
8 详情：左播放，右编辑标题/简介/封面/话题；操作：确认成片、让 Grokbot 修改、准备发布。
9 发布：选平台 → 确认封面文案 → 确认发布，同页预览各平台；不能直发的给下载视频/复制文案/下载封面；区分已导出/已发布，拿到真实结果才标发布并记平台+时间。
10 客户展示视图：独立页，只放精选案例与简介，隐藏测试/废片/内部名/待审；突出「播放案例」「用同款制作」。
11 视觉：保留黑红影院风，工作台减装饰，强品牌留给展示页；宋体仅大标题，其余苹方；灰字提亮；红色只给关键按钮与选中。
实施顺序：一 导航/状态/分类/压顶/合并版本；二 接通 Grokbot 成套入库；三 审核与发布流程；四 客户展示与视觉打磨。
