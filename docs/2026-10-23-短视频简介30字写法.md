# 短视频简介 ≤30 字写法（发布官专用）

> **六伟定（2026-10-23）**
> 1. 所有短视频简介硬顶 **≤30 字**（太长没人看）。字数按汉字计，标点也算。
> 2. 简介**一律由短视频发布官统一写**。操盘手（1–6 号、实验室）出片时**只交标题和成片，不写简介**。
>
> 简介 ≠ 标题。标题负责点开，简介负责扫一眼就懂。你（发布官）在点「发布」前，根据标题 + 成片内容现写一句，不要让操盘手代写，也不要把标题整段粘进简介框。

## 0. 你的工作流（发布前 30 秒）

1. 打开待发布条目：看**标题**和成片前 3～5 秒在讲什么。
2. 用下面「三选一」写一句 ≤30 字简介（可先打草稿再数一遍字）。
3. 过一遍第 4 节禁用清单；超字或踩坑就改，**绝不带着超长简介发出去**。
4. 三平台可共用同一句核心，再按第 2 节微调语气（仍都 ≤30）。

操盘手若误交了简介：忽略，以你写的为准。

## 1. 结构公式（三选一，不要三样全塞）

30 字塞不下「钩子 + 结论 + 利益」三件套，只留**最强的一件**，最多再加半句。

| 公式 | 排法 | 适用产线 |
|---|---|---|
| **A. 结论前置** | 一句话结论 +（可选）半句反差 | 观点口播、文哲、心理科普 |
| **B. 钩子留白** | 半截悬念或冲突，答案在视频里 | 3D 地图、人物传记、AI 新闻 |
| **C. 利益点** | 看完能带走什么（方法/避坑） | 教程感口播、宣传片 |

叠招参考标题六招 + 借势 + 简短：贴标签、设悬念、造冲突、做留白、撩色欲、送好处、借势。简介比标题更短，**优先造冲突或结论**；撩色欲在简介里慎用（比标题更容易被限）。

发布前自检：
1. 去掉后数一遍，≤30 字吗？
2. 和标题说的是同一件事，但**不是把标题整段粘贴**吗？
3. 陌生人只看简介，能知道这条在讲什么吗？

## 2. 平台差异（都 ≤30 字）

| 平台 | 你怎么写 | 话题 |
|---|---|---|
| **视频号** | 偏口语，像朋友圈一句；可带半句互动（「你怎么看」算字数） | 少加或不加 |
| **抖音** | 更冲；数字和热词优先（借势） | 最多 1～2 个，禁止堆一长串 |
| **小红书** | 略「笔记感」：结论 + 半句体验；少用震惊体 | 最多 2 个 |

同一条片子：先定一句 ≤30 的核心，抖音把动词写冲一点，小红书加半拍「我/体验」，**不要写成三篇不同长文**。

发到哪个视频号（袁六伟 / 山河来电 / 汇芯袁总）按既有内容分工，简介写法不变，只改语气贴合账号。

## 3. 按产线取材：合格样例 + 超长改短

下面样例供你对照「这种片大概写成什么样」。发布时按**本条标题和内容**现写，不要机械复用。字数发布前用编辑器再数一遍。

### 3.1 心理科普
- 别再用意志力戒手机，换这个开关。（17）
- 你不是懒，是大脑在省电。（12）
- 拖延的真相：怕的不是事，是评价。（16）

反例改短：  
超长「今天跟大家聊聊为什么我们总是管不住自己刷手机……」→ **刷手机停不下来，不是你没自制力。（18）**

### 3.2 文哲类
- 庄子说的「无用」，其实最有用。（14）
- 你焦虑，是因为把人生当成了考试。（16）
- 读懂这一句，少内耗十年。（12）

反例改短：  
超长「本期我们从《逍遥游》出发……」→ **活得累，不是事多，是心没地方放。（16）**

### 3.3 人物传记
- 老板让AI裁员，AI先把他裁了。（14）
- 她用AI回消息，对象以为换人了。（15）
- 打工人VS人工智能，结局你猜不到。（16）

注意：人物传记简介**不要剧透结局**。

### 3.4 3D 地图（发「山河来电」）
- 少修一条河，他是不是千古一帝？（14）
- 四路大军扑一座城，五天没了三路。（15）
- 诸葛亮一辈子，没吃过一口辣椒。（14）

反例改短：  
超长「本期3D地图带你穿越回隋朝……欢迎关注山河来电」→ **骂了千年的昏君，修的河今天还在跑船。（17）**  
（「欢迎关注」类空话一律删。）

### 3.5 口播 / AI 新闻（多发主号「袁六伟」）
- AI啥都能干，年轻人却花钱拼豆。（14）← 借势
- 字节借了296亿，28家银行抢着给。（16）
- 这周AI三件事，一人公司必看第二条。（16）

数字必须来自成片/标题里已有且可靠的出处；成片没提的数字不要写进简介。

### 3.6 宣传片 / 带货
- 一人公司，我只干这四件事。（12）
- 一人公司怎么用AI？先看这支片。（14）
- 先看完再交学费，问自己这三个问题。（16）

**价格、名额、开营时间禁止写进简介**，除非 `/workspace/统一事实表.md` 有且六伟批准。简介只负责吸引点开，成交话术走合规入口，不写进简介正文。


### 3.7 实验室（新形式小样）
- 这个形式值不值得量产？看完说话。（15）
- 同一条内容，三种包装，你更吃哪一种？（16）
- 内测片：先看效果，再决定上不上号。（14）

实验室片默认偏内测：简介不要写成正式招生，也不要「欢迎来主号看更多」；测完再定账号话术。

## 4. 禁用与踩坑（发布官验收清单）

**直接打回重写（你自己改，或退回让制片方改标题——简介仍是你写）**
- 空话：精彩呈现、不容错过、干货满满、建议收藏、家人们、宝子们、欢迎关注xxx
- 把**标题整段**复制进简介
- 话题堆砌：五个以上 `#`
- 收益承诺：月入、必赚、稳赚、躺赚、包教会
- 极限词：最牛、第一、绝对、国家级（宣传片尤其危险）
- 站外导流裸写：加微信、私信领资料
- 未进统一事实表的价格、名额、开营时间
- **超过 30 字**

**常见踩坑**
1. 简介写成第二标题，比标题还长 → 删到一句。
2. 人物传记/地图剧透反转 → 改留白。
3. 为借势堆三个热词 → 只留一个最强热词。
4. 三个平台贴同一段 80 字小作文 → 压到 30 内再微调。

## 5. 和标题的分工

| | 标题（操盘手交） | 简介（你写） |
|---|---|---|
| 字数 | ≤20 优先，要短 | ≤30，硬顶 |
| 谁写 | 操盘手 / 文案官出备选，六伟或产线定 | **仅发布官** |
| 职责 | 让人点开 | 点开前再确认「这条有用」 |
| 数字与点名 | 敢写、有出处 | 同左，更短：只留一个数字或一个名字 |

**硬规则：超 30 字的简介不得发布。**
